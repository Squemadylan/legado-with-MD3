# TTS 章节音频缓存说明

[[toc]]

## 功能概述

阅读页右上角「⁝」菜单中的 **缓存音频**（与「添加书签」同级），可为当前书籍按章节、按段落预合成并保存 HTTP / 豆包 / MiMo TTS 音频。

系统本地 TTS **不支持**该功能。

## 存储位置

```
Download/Yuedu/{书名}TTS/{章序号_章标题}/{段序号}.mp3|.wav
```

- 一书一个 `{书名}TTS` 目录
- 一章一个子目录
- 一段一个音频文件（序号与朗读段落列表对齐，**含章节标题为第 0 段**）

## 批量「缓存音频」

| 情况 | 行为 |
| --- | --- |
| 该段尚无本地文件 | 调用 TTS 合成并写入 |
| 该段已有 `.mp3` / `.wav` | **跳过**合成，进度仍计为完成 |
| 纯标点/空白段（如「……」） | 不生成任务 |

写入接口本身支持覆盖同位置；批量缓存任务在写入前会先检查文件是否存在，存在则跳过。

缓存进行中仍可开启朗读：朗读优先读本地已缓存文件，不抢占合成、不干扰缓存进度。

## 朗读时自动落盘

即使未点「缓存音频」，只要使用 HTTP / 豆包 / MiMo 朗读并成功合成某段，也会自动写入上述目录。

| 情况 | 行为 |
| --- | --- |
| 持久缓存已有该段完整音频 | **优先播放缓存**，不再合成 |
| 无缓存且合成成功 | 写入持久目录（同位置覆盖） |
| 临时目录已有、持久目录没有 | 可将临时文件同步落盘 |

## 页中截断段（段中起读）是否落盘？

**不会写入章节持久缓存。**

典型场景：手动翻到下一页，该页首行是上一页未读完的**跨页段落**（截断段）。此时：

1. 有网时：从**截断处（段中）**起读，只合成后半截文本
2. 没网时：往往无法从截断处起读，可能从下一段继续（取决于是否已有可用缓存）

实现上，段中起读（`paragraphStartPos > 0`）时：

- **不读** `Download/...TTS/` 中该段的完整缓存（完整段与截断文本对不上）
- **不写** 持久缓存，避免把「后半截音频」覆盖掉整段文件

截断部分若有网合成，只会进入应用临时目录（`httpTTS`，按截断文本 MD5），**不会**落成章节缓存里的 `000x.mp3|.wav`。

只有从**段首**完整朗读并新合成时，才会自动写入章节缓存。
